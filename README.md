# ⚡ AI Deal & Promo Finder (Chrome Extension)

A lightweight, zero-API-key Chrome Extension (Manifest V3) that searches Reddit communities and GitHub repositories in real time for active AI promo codes, referral credits, and free API tiers.

## Features
- **Zero Configuration:** Works out of the box without paid search API keys.
- **Auto-Code Detection:** Automatically scans post titles and descriptions for promo codes with one-click copy.
- **Google Dork Generator:** Builds targeted boolean search queries to uncover hidden discount pages across the web.
- **Local Caching:** Remembers your last search using `chrome.storage.local`.
